# Part 01 · Meet Claude

## 01. What is Claude?

**학습 목표** — Claude가 무엇이고 그 설계 원칙은 무엇인지, 단순 챗봇과의 차이, 접근 방법(웹·데스크톱·모바일)을 이해한다.

### 핵심 요약

- **helpful · harmless · honest로 설계됨** — 유해·차별적 출력과 불법·비윤리적 조력을 피하도록 원칙에 따라 행동한다. 이 접근을 **Constitutional AI**라 하며, 인간 가치에 정렬되고 투명하게 작동하도록 학습됐다.
- **챗봇 이상의 존재** — 요약·검색·창작/협업 글쓰기·Q&A·코딩 등 폭넓은 작업을 높은 신뢰성으로 수행한다. 단순 답변기가 아니라 복잡한 문제를 함께 푸는 **사고의 파트너**.
- **조종 가능하고 협업적** — 성격·톤·행동 지시를 받아들이며, 유해 출력이 적고 대화가 쉬워 더 적은 노력으로 원하는 결과를 얻는다.
- **어디서나 접근 가능** — Free·Pro·Max·Team·Enterprise 모든 플랜에서 제공. 로그인하면 대화·프로젝트·메모리·선호가 모든 기기에 동기화된다.

### Claude의 역량

단순 문답을 넘어 업무를 **자동화(automate)**하고 **증강(augment)**하는 비서형 파트너로 작동한다.

| 영역 | 설명 |
|---|---|
| **글쓰기·콘텐츠** | SNS 게시물·이메일·보고서를 함께 작업. 성격·톤 지시를 반영해 당신의 목소리를 살린다. |
| **리서치·분석** | 관점 탐색·정리·데이터 분석으로 통찰 도출. 큰 컨텍스트 윈도우(20만+ 토큰 ≈ 500쪽 이상, Pro·Max·Team·Enterprise는 최대 100만 토큰)로 방대한 자료를 한 대화에서 고려. |
| **코딩 지원** | Claude의 최대 강점 중 하나. 여러 언어에서 코드 작성·디버깅·설명. |
| **문제해결·추론** | 최신 Opus·Sonnet은 즉답과 **확장 사고(extended thinking)**를 제공하는 하이브리드 모델로 단계적으로 깊게 추론. |
| **학습** | 답을 주기보다 **추론 과정을 이끄는 Learning mode**로 비판적 사고력을 키운다. |

### 접근 방법

- **Claude.ai** (웹·모바일·데스크톱) — 대부분의 사람이 쓰는 기본 경로. 질문·브레인스토밍·문서 작성·리서치·파일 생성. **본 과정의 주 초점**.
- **Claude Code** — 개발자용 에이전트형 코딩 도구. 파일 직접 편집·명령 실행·커밋.
- **Claude in Slack** — 채널·DM·파일을 검색해 맥락을 찾고 `@Claude` 멘션으로 대화.
- **Claude for Excel** — 엑셀 사이드바에서 워크북을 읽고 분석·수정·생성.

## 02. Your first conversation with Claude

**학습 목표** — 새 대화 시작과 인터페이스, 효과적인 프롬프트 작성, 파일·이미지 업로드, 후속 메시지로 반복(iterate)하기.

### 핵심 요약

- Claude는 모든 업무에서 능력을 증폭시키는 **지적 협업 파트너**다. AI는 지능을, 당신은 맥락과 전문성을 제공한다.
- **동료에게 말하듯** 자연스럽고 간결하게 말하는 것이 가장 좋다.
- 업로드한 문서·배경 정보는 응답에 반영된다 — 필요를 빠르게 이해시키는 지름길.
- 진짜 힘은 일회성 프롬프트가 아니라 **지속적이고 잦은 소통**에서 나온다.

### 효과적인 프롬프트 3요소

| 요소 | 스스로에게 던질 질문 |
|---|---|
| **무대 설정** (Setting the stage) | 내 역할과 목표는? Claude가 알아야 할 맥락이 있나? |
| **작업 정의** (Defining the task) | 어떤 행동을 원하나? (쓰기 / 분석 / 제작) |
| **규칙 지정** (Specifying rules) | 어떤 스타일·톤? 보여줄 예시가 있나? |

> **세 요소를 모두 담은 예시** — "저는 인디 스트리밍 스타트업의 마케팅 리드이고 시리즈 A 투자자용 피치덱을 준비 중입니다. 독립 영화 스트리밍 시장 현황을 조사해 주요 트렌드·경쟁사 포지셔닝·성장 기회를 정리해 주세요. 출처를 포함한 최신 웹 리서치를 활용하고, 경영진 요약·시장 분석·경쟁 구도·성장 기회로 구성된 최대 5페이지 보고서로 작성해 주세요."

이 프레임워크는 **AI Fluency의 4D Framework**(Delegation·Description·Discernment·Diligence)에서 가져온 것이다.

### 맥락 추가하기

Claude는 PDF·문서의 **텍스트와 시각 요소(이미지·차트)**를 모두 분석한다. 지원 형식: `PDF` `DOCX` `CSV` `TXT` `PNG` `JPEG`

- 문서를 올리고 핵심 요점 요약 요청
- 이미지를 공유하고 내용 묘사·분석 요청
- 스프레드시트를 첨부하고 트렌드 식별 요청
- 코드를 올리고 동작 설명·버그 찾기 요청

### 응답 다듬기 (Iterating)

- **후속 질문**: "두 번째 포인트 더 자세히", "더 간결하게"
- **피드백 제공**: "좋은데 톤이 너무 격식적이야. 더 대화체로"
- **방향 전환·재시작**: "사실 Y가 아니라 X를 물은 거였어" — 꼬이면 새 채팅으로 맥락 리셋

> **개인화** — **Memory**는 역할·선호·과거 결정을 자동 저장해 반복 설명을 없앤다. **Styles**는 소통 방식(concise·formal·explanatory 등)을 커스터마이즈해 모든 대화에 자동 적용한다.

## 03. Getting better results

**학습 목표** — AI 초기의 흔한 문제를 트러블슈팅하고, AI Fluency를 정의하며, 내 워크플로우에서 Claude를 평가하는 evals를 이해한다.

### 흔한 문제와 해결법

| 문제 | 원인 | 해결책 |
|---|---|---|
| 응답이 너무 일반적 | 상황 맥락 부족 | 청중·역할·제약 추가. "지연 이메일 써줘" → "엔터프라이즈 고객에게 2주 지연을 알리되 두 번째 지연이라 사과하면서도 전문적으로" |
| 너무 길다 / 짧다 | 적정 길이를 추측 중 | 명시: "2문단 요약", "100단어 이내" |
| 형식을 안 지킴 | *어떻게* 보여줄지 모름 | 말 말고 **예시를 보여줘라** |
| 그럴듯한데 틀린 정보 | 특정 사실·틈새 주제 | **독립 검증**, 출처·확신도 요청, **웹 검색** 켜기 |
| 톤이 안 맞음 | 기본값이 친절·전문적 | 평범한 말로 묘사 + 예시 제공 |

### 반복(Iteration) 마인드셋

> **첫 프롬프트가 완벽한 결과를 내는 일은 드물다 — 그래도 괜찮다.** 첫 프롬프트는 대화의 시작이지 일회성 요청이 아니다.

- 초안을 **출발점**으로 취급
- **구체적 피드백**: "짧게"보다 "앞 두 문단 빼고 결론을 행동 중심으로"
- 꼬이면 **새 채팅**이 더 빠를 수 있다

### AI Fluency — 4D Framework

| 역량 | 의미 |
|---|---|
| **Delegation** 위임 | 인간이/AI가 할 일을 정하고 분배 |
| **Description** 기술 | 원하는 출력·과정·동작을 명확히 정의 |
| **Discernment** 분별 | 출력·과정·동작을 비판적으로 평가 |
| **Diligence** 성실 | 책임감 있고 윤리적으로 사용 |

### Evals — 내 워크플로우에서 평가하기

**Evals**는 중요한 작업에서 Claude 출력을 체계적으로 테스트하는 방법이다. 복잡한 인프라가 필요 없다.

1. **예시 수집** — 자주 하는 작업 샘플 5~10개
2. **테스트 프롬프트 작성** — 비슷한 출력을 낼 프롬프트 + 평소 맥락
3. **출력 비교** — 핵심 정보 포착? 톤 적절? 빠진 점은?
4. **접근 다듬기** — 프롬프트 조정, 인간 검토 필수 지점 식별

## 04. Claude desktop app: Chat, Cowork, Code

데스크톱 앱은 빠른 질문부터 복잡한 리서치, 소프트웨어 제작까지 세 모드로 Claude와 일하게 한다. **Cowork와 Code는 같은 엔진(내부적으로 둘 다 Claude Code)** 위에서 돈다.

| 모드 | 한 줄 정의 |
|---|---|
| **Chat** | claude.ai와 같은 Claude + 네이티브 실행에서 오는 빠른 진입·스크린샷·받아쓰기·커넥터 |
| **Cowork** | 목표를 주고 도구·자료를 연결하면 알아서 일하는 에이전트. 깊은 리서치·분석과 복잡한 산출물 |
| **Code** | 코드 작성·테스트부터 배포까지, 소프트웨어를 만드는 모드 |

### Chat

claude.ai와 동일하되 컴퓨터에서 네이티브로 실행되어 더해지는 기능이 있다 — **빠른 진입**(Mac에서 Option 두 번 탭 → 작업 위에 떠오름), **스크린샷·창 공유**, **받아쓰기(Dictation)**, **데스크톱 커넥터**.

### Cowork

여러 출처에서 정보를 끌어와 완성품을 내는, 품이 드는 작업용. 시작 전 보통 범위·형식·제약을 묻는 짧은 질문으로 **계획(plan)**을 세운다. 주요 기능: 폴더 접근, 예약 작업, 서브에이전트, Dispatch(모바일), Projects, 브라우저 사용, 컴퓨터 사용, 플러그인, 보호된 환경. (Pro·Max·Team·Enterprise)

### Code

데스크톱 앱 안에서 **Claude Code**를 그대로 돌려 소프트웨어를 만든다. 비주얼 diff·내장 터미널·git 추적. Cowork가 공유 폴더로 제한된다면 Code는 파일시스템·터미널에 **전체 접근**.

- **작업 위치** — Local(내 컴퓨터 폴더) / Remote(GitHub 저장소, 앱 닫아도 세션 유지)
- **상호작용 모드** — Ask(모든 변경 승인 대기) / Code(파일 자동, 명령은 확인) / Plan(먼저 전체 설계)

| 구분 | Chat | Cowork | Code |
|---|---|---|---|
| **최적화 대상** | 빠른 교환·반복 초안·학습 | 복잡·지속 작업, 리서치·분석·산출물 | 소프트웨어 빌드 |
| **핵심 기능** | 빠른 진입, 받아쓰기 | 로컬 폴더, 플러그인, 서브에이전트, 예약 작업 | Ask/Code/Plan, diff, git, 로컬·원격 |

# Part 02 · 업무와 지식 정리

## 05. Introduction to projects

프로젝트는 **자체 메모리·대화 기록·지식 베이스·맞춤 지침**을 갖춘 독립 워크스페이스다. 한 번 올린 자료는 그 프로젝트의 모든 대화가 참조하므로 **같은 파일을 매번 다시 올릴 필요가 없다**.

| 핵심 요소 | 역할 |
|---|---|
| **프로젝트 지식** | 올린 문서를 모든 대화에서 참조. 반복 업로드 제거 |
| **프로젝트 지침** | 톤·전문성·형식 등 행동을 모든 대화에 일괄 적용 |
| **자동 확장(RAG)** | 지식이 컨텍스트 한계에 가까워지면 자동으로 RAG 전환 → 용량 최대 10배 |
| **협업** | (Team·Enterprise) 같은 맥락·지침·지식을 팀과 공유 |

### 만들기 (3단계)

1. **설정** — 사이드바 Projects → + New Project → 이름·설명·공개 범위
2. **지침** — 작업 맥락·프로세스·톤·요구사항을 적고 Save. *"회의록을 올리면 이 템플릿으로 요약해라"*처럼 워크플로우 자동화도 가능
3. **지식 베이스** — PDF·DOCX·CSV·TXT·HTML 업로드 또는 Google Drive 연결

> **파일명 팁** — Claude는 파일명으로 내용을 파악·검색한다. "document1.pdf"보다 "Q4-2024-Brand-Guidelines.pdf"가 훨씬 유용하다.

### 협업 권한 (Claude for Work)

- **Can view** — 보기·대화 가능, 변경 불가
- **Can edit** — 지침 수정·지식 갱신·멤버 관리
- **Owner** — 공개 대상까지 모든 것을 통제

## 06. Creating with artifacts

아티팩트는 Claude가 **대화 옆 전용 창에 만들어 주는 독립적·상호작용 산출물**이다. 긴 코드·텍스트가 채팅에 파묻히는 대신 작동하는 웹사이트·차트·문서로 렌더링된다. 보통 15줄 이상의 자기완결적이고 재사용할 내용일 때 **자동 생성**된다.

| 종류 | 용도 |
|---|---|
| **문서** | Markdown·Word·PDF·PPT·Excel — 보고서·기획서·블로그 |
| **코드 스니펫** | 모든 언어의 작동 코드 |
| **HTML 페이지** | 한 파일 웹페이지·랜딩·프로토타입 |
| **SVG 이미지** | 로고·아이콘·일러스트 |
| **Mermaid 다이어그램** | 플로차트·시퀀스·간트 |
| **React 컴포넌트** | 계산기·대시보드 등 인터랙티브 UI |

### 공유 & 게시

- **복사·다운로드** — 개인용
- **조직 내 공유** (Team·Enterprise) — 팀 인증 필요
- **공개 게시** (Free·Pro·Max) — 링크로 누구나 접근, 선택 버전만 공개(대화는 비공개), 타인이 "remix" 가능. 검색엔진 색인은 안 됨.

> **팁** — 원하는 바를 구체적으로, 최종 사용자를 알려주고, 한 번에 하나씩 점진적으로 반복하라.

## 07. Working with skills

Skills는 Claude가 **특정 작업을 잘하기 위해 동적으로 불러오는 지침·스크립트·자료의 폴더**다. '전문성 패키지'로, Excel·PPT·Word·PDF 생성이 이미 Skills로 동작한다. 분기 변동 분석·브랜드 리뷰 같은 **반복 워크플로우 전체를 코드화**할 수 있다. *(현재 Pro·Max·Team·Enterprise 기능 프리뷰)*

- **Anthropic Skills** — Anthropic이 유지하는 문서 생성 등. 관련 상황에서 **자동 호출**
- **Custom Skills** — 나·조직이 만든 특화 워크플로우

### 만들기 — 대화로

코드를 쓸 필요 없이 Claude와 대화하면 된다. (1) 만들 것 설명 → (2) Claude의 인터뷰에 답 → (3) 참고 자료 업로드 → (4) 저장. 사이드바 **Customize** 탭에서 관리한다.

### Skills vs Projects

**프로젝트는 지식을 저장하고, 스킬은 작업을 수행한다.**

| 구분 | Projects | Skills |
|---|---|---|
| **목적** | 참조할 지식 저장 | 실행할 절차 정의 |
| **적합** | 장기 맥락·참조 자료·협업 | 반복 워크플로우·일관된 방법론 |
| **지속성** | 모든 대화에서 지식 사용 | 호출될 때 지침 적용 |

# Part 03 · 활용 범위 넓히기

## 08. Connecting your tools

커넥터는 매일 쓰는 도구·데이터에 Claude를 연결해 **단순 어시스턴트에서 정보에 밝은 협업자로** 바꾼다. 권한에 따라 파일 검색·문서 가져오기·데이터 분석·레코드 업데이트를 대화 안에서 수행한다.

> **MCP가 커넥터를 움직인다.** Model Context Protocol은 'AI를 위한 USB-C' — 하나의 표준으로 수많은 앱에 연결되는 개방 인터페이스다.

- **웹 커넥터** — Google Drive·Notion·Slack·Asana 등 클라우드 서비스
- **데스크톱 확장** — Claude 데스크톱 앱으로 로컬 파일·네이티브 앱 접근

디렉터리: `claude.ai/directory`. 연결 흐름은 찾기 → Connect → 인증 → 권한 허용 → 테스트.

| 분야 | 예시 |
|---|---|
| 프로젝트 관리 (Asana·Linear·Jira) | "이번 주 마감 최우선 작업은?" |
| 커뮤니케이션 (Slack·Gmail) | "벤더 계약 논의 스레드 찾아줘" |
| 문서 (Notion·Drive·Confluence) | "브랜드 보이스 가이드 검색" |
| 비즈니스 (Stripe·Salesforce) | "지난 분기 매출 추이" |

> **보안** — 권한은 범위 제한적이고, Claude는 *내가 접근 가능한 데이터만* 본다. 언제든 연결 해제 가능. 커스텀 커넥터는 신뢰 출처에서만.

## 09. Enterprise search

사이드바에 **"Ask {조직명}"** 항목을 추가해 회사 여러 도구에 흩어진 지식을 찾고 종합한다. **조직 전체를 위한 미리 만들어진 프로젝트**로, 정보 수집에 특화된 맞춤 지침을 쓴다. *(Team·Enterprise 전용, 관리자 설정 필요)*

질문하면 SharePoint·Slack·Gmail·Drive를 가로질러 검색해 **하나의 통합 응답**으로 종합하고 항상 **출처를 인용**한다.

| 용도 | 예시 |
|---|---|
| 업무 따라잡기 | "내가 자리 비운 어제 무슨 일 있었어?" |
| 정책·프로세스 | "재택근무 정책은?", "경비 보고서 제출법은?" |
| 신규 온보딩 | "인증 시스템은 어떻게 작동해?" |
| 프로젝트 추적 | "지난주 리더십 회의 핵심 결정은?" |

설정은 두 단계 — 관리자가 조직용으로 구성한 뒤 사용자가 개별 인증. **이미 접근 권한이 있는 것만** 보여주므로 안전하다.

## 10. Research mode for deep dives

Research는 Claude를 **체계적 조사자**로 바꾼다. 한 번의 검색이 아니라 **에이전트처럼** 찾은 내용을 바탕으로 다음을 정하며 서로 이어지는 여러 검색을 수행한다. 보통 **5~15분(복잡하면 최대 45분)**에 끝나고, **확장 사고가 자동으로 켜지며**, 모든 주장에 **검증 가능한 인용**이 붙는다.

### 언제 쓰나

| 기능 | 이럴 때 |
|---|---|
| **Research** | 여러 출처 종합 리포트, 비교 분석, 인용 필요한 심층 조사 |
| 웹 검색 | 빠르고 구체적인 사실 하나, 출처 한두 개 |
| 확장 사고 | 외부 정보 없이 추론(수학·코드 디버깅) |
| Enterprise Search | 조직 내부 지식에서 답을 찾을 때 |

### 작동 (4단계)

1. **계획** — 확장 사고로 요청 분해·조사 각도 설계
2. **다중 검색** — 찾은 것에 따라 다음을 정하고 빈틈 메움
3. **종합** — 웹·통합에서 모은 정보를 구조화된 리포트로
4. **인용** — 모든 주장이 출처로 연결

> **팁** — 목표를 구체적으로, 원하는 구조·섹션을 명시하고, 제약(예산·일정)을 포함하라. 채팅 **+ → Research** 선택, **웹 검색이 켜져 있어야** 작동한다.
