핵심 요약

  • helpful · harmless · honest로 설계됨 — 유해·차별적 출력과 불법·비윤리적 조력을 피하도록 원칙에 따라 행동. 이 접근을 Constitutional AI라 하며, 인간 가치에 정렬되고 투명하게 작동하도록 학습됨.
  • 챗봇 이상의 존재 — 요약·검색·창작/협업 글쓰기·Q&A·코딩 등 폭넓은 작업을 높은 신뢰성·예측가능성으로 수행. 단순 답변기가 아니라 복잡한 문제를 함께 푸는 사고의 파트너.
  • 조종 가능하고 협업적 — 성격·톤·행동에 대한 지시를 받아들이며, 유해 출력이 적고 대화가 쉬워 더 적은 노력으로 원하는 결과를 얻을 수 있음.
  • 어디서나 접근 가능 — Free·Pro·Max·Team·Enterprise 모든 플랜에서 제공. 로그인하면 대화·프로젝트·메모리·선호가 모든 기기에 동기화. 웹·데스크톱·모바일 앱 지원.

Claude의 역량 이해하기

Claude는 단순 문답을 훨씬 넘어, 업무를 자동화(automate)하고 증강(augment)하는 비서형 파트너로 작동합니다. 잘하는 일들:

영역설명
글쓰기·콘텐츠SNS 게시물, 비즈니스 이메일, 복잡한 보고서를 함께 작업. 성격·톤 지시를 반영해 구조와 명료성을 함께 다듬어 당신의 목소리를 살림.
리서치·분석관점 탐색·findings 정리·데이터 분석으로 통찰 도출. 큰 컨텍스트 윈도우(20만+ 토큰 ≈ 500쪽 이상, Pro·Max·Team·Enterprise는 지원 모델에서 최대 100만 토큰) 덕에 방대한 자료를 한 대화에서 고려.
코딩 지원Claude의 최대 강점 중 하나. 여러 언어에 걸쳐 코드 작성·디버깅·설명을 도움.
문제해결·추론복잡한 인지 과제·수학·전략적 사고. 최신 Opus·Sonnet은 하이브리드 모델로 즉답 모드와 확장 사고(extended thinking) 모드를 제공해 단계적으로 깊게 추론.
학습새 기술·낯선 분야를 내 학습 속도에 맞춰 안내. 답을 주기보다 추론 과정을 이끄는 Learning mode로 비판적 사고력을 키움.
💡 내 직무에 맞는 활용 아이디어는 claude.com의 use-case 갤러리에서, AI의 가능·한계를 더 깊이 보려면 AI Capabilities 코스를 참고하세요.

Claude에 접근하는 방법

Claude는 '지능' 그 자체이고, 같은 지능을 여러 인터페이스에서 만날 수 있습니다. 각 인터페이스는 다른 종류의 작업에 적합합니다.

  • Claude.ai (웹·모바일·데스크톱 앱) — 대부분의 사람이 쓰는 기본 경로. 질문·브레인스토밍·문서 작성/편집·리서치·분석·파일 생성에 이상적. 본 과정의 주 초점.
  • Claude Code — 개발자용 에이전트형 코딩 도구지만 데스크톱의 온갖 파일 작업에 사용 가능. 파일을 직접 편집하고 명령 실행·커밋 생성.
  • Claude in Slack — 팀 소통 도구 안으로 Claude를 가져옴. 채널·DM·공유 파일을 검색해 맥락을 찾고, @Claude 멘션으로 스레드에서 대화.
  • Claude for Excel — 엑셀 사이드바에서 워크북을 읽고 분석·수정·생성. 모델 분석, 가정 업데이트, 오류 디버깅, 템플릿 채우기, 수식 설명, 멀티탭 탐색에 적합.

Meet Claude · 레슨 02

Your first conversation with Claude

⏱ 20분 🎬 영상

학습 목표

  • Claude와 새 대화를 시작하고 인터페이스 다루기
  • 명확하고 구체적인 언어로 효과적인 프롬프트 작성하기
  • 파일·이미지를 업로드해 추가 맥락 제공하기
  • 후속 메시지로 응답을 다듬고 반복(iterate)하기

핵심 요약

  • Claude는 모든 업무에서 능력을 증폭시키는 지적 협업 파트너다. AI는 지능을, 당신은 맥락과 전문성을 제공한다.
  • 동료에게 말하듯 자연스럽고, 간결하고, 대화하듯 말하는 것이 가장 좋다.
  • 업로드한 문서·배경 정보는 응답에 반영된다 — Claude가 필요를 빠르게 이해하는 지름길.
  • 진짜 힘은 일회성 프롬프트가 아니라 지속적이고 잦은 소통에서 나온다.

효과적인 프롬프트 3요소

요소스스로에게 던질 질문
무대 설정 (Setting the stage)내 역할과 목표는? Claude가 알아야 할 업무 맥락이 있나?
작업 정의 (Defining the task)Claude가 어떤 행동을 하길 원하나? (쓰기 / 분석 / 제작 등)
규칙 지정 (Specifying rules)어떤 스타일·톤? 보여줄 예시가 있나?

세 요소를 모두 담은 예시 프롬프트

"저는 인디 스트리밍 스타트업의 마케팅 리드이고, 시리즈 A 투자자용 피치덱을 준비 중입니다. 독립 영화 스트리밍 시장 현황을 조사해 주요 트렌드·경쟁사 포지셔닝·성장 기회를 정리해 주세요. 출처를 포함한 최신 웹 리서치를 활용하고, 경영진 요약·시장 분석·경쟁 구도·성장 기회로 구성된 최대 5페이지 전문 보고서로 작성해 주세요."
📚 이 프레임워크는 AI Fluency의 4D Framework(Delegation·Description·Discernment·Diligence)에서 가져온 것으로, Rick Dakan 교수(Ringling College)와 Joseph Feller 교수(University College Cork)의 공동 연구입니다. 무료 AI Fluency 강좌에서 더 배울 수 있습니다.

맥락 추가하기

Claude는 PDF·문서의 텍스트와 시각 요소(이미지·차트)를 모두 분석합니다. 지원 형식: PDF DOCX CSV TXT PNG JPEG

  • 문서를 올리고 핵심 요점 요약 요청
  • 이미지를 공유하고 내용 묘사·분석 요청
  • 스프레드시트를 첨부하고 트렌드 식별 요청
  • 코드를 올리고 동작 설명·버그 찾기 요청
Pro-tip: 모든 대화에 적용할 선호도는 Settings > General > 'What personal preferences should Claude consider?'에서 설정하세요.

응답 다듬기 (Iterating)

  • 후속 질문: "두 번째 포인트 더 자세히", "더 간결하게 해줄래?"
  • 피드백 제공: "좋은데 톤이 너무 격식적이야. 더 대화체로"
  • 방향 전환·재시작: "사실 Y가 아니라 X를 물은 거였어"… 최악의 경우 새 채팅으로 맥락 리셋
Pro-tip: 내 메시지의 연필 아이콘으로 프롬프트를 수정·재전송할 수 있습니다.

Claude 개인화하기

Memory — 역할·선호·과거 결정·업무 스타일을 자동 저장해 반복 설명을 없앰. Settings에서 확인·수정·삭제, 모든 기기 동기화.

Styles — 소통 방식 커스터마이즈(concise·formal·explanatory 프리셋 또는 직접 정의). 설정하면 모든 대화에 자동 적용.

흔한 문제와 해결법

문제원인해결책
응답이 너무 일반적내 상황 맥락이 부족청중·역할·제약 추가. "지연 이메일 써줘" → "엔터프라이즈 고객에게 2주 지연을 알리되, 두 번째 지연이라 사과하면서도 전문적으로"
너무 길다 / 짧다적정 길이를 추측 중명시: "2문단 요약", "100단어 이내", "길이 신경 안 써—종합 분석"
형식을 안 지킴무엇은 알지만 어떻게 보여줄지 모름말 말고 예시를 보여줘라. "각 섹션 굵은 헤더 + 불릿"
그럴듯한데 틀린 정보특정 사실·틈새 주제에서 가끔 발생중요한 일은 독립 검증. 출처 인용·확신도 요청, 웹 검색 켜기
톤이 안 맞음기본값이 친절·전문적평범한 말로 묘사: "더 대화체로", "권위 있게" + 예시 제공

반복(Iteration) 마인드셋

첫 프롬프트가 완벽한 결과를 내는 일은 드물다 — 그래도 괜찮다. 첫 프롬프트는 대화의 시작이지 일회성 요청이 아니다.
  • 초안을 출발점으로 취급
  • 구체적 피드백: "짧게"보다 "앞 두 문단 빼고 결론을 행동 중심으로"
  • 새로 시작할 때를 안다: 꼬이면 명확한 프롬프트로 새 채팅이 빠를 수 있음

AI Fluency란? — 4D Framework

역량의미
Delegation 위임인간이/AI가 할 일을 정하고 분배. 목표·AI 역량을 이해해 전략적으로 협업 선택.
Description 기술AI와 효과적 소통. 원하는 출력·과정·동작을 명확히 정의.
Discernment 분별출력·과정·동작을 비판적으로 평가. 품질·정확성·적절성 판단.
Diligence 성실AI를 책임감 있고 윤리적으로 사용. 투명성·책임.
레슨 2의 프롬프트 프레임워크는 Description에, 위 트러블슈팅은 Discernment·Diligence에 뿌리를 둡니다.

내 워크플로우에서 Claude 평가하기 (Evals)

Evals는 내게 중요한 작업에서 Claude 출력을 체계적으로 테스트하는 방법입니다. 복잡한 인프라가 필요 없습니다.

간단한 평가 절차

  1. 예시 수집 — 자주 하는 작업 샘플 5~10개
  2. 테스트 프롬프트 작성 — 비슷한 출력을 낼 프롬프트 + 평소 맥락
  3. 출력 비교 — 핵심 정보 포착? 톤·스타일 적절? 빠진 점은?
  4. 접근 다듬기 — 프롬프트 조정, 예시 추가, 인간 검토 필수 지점 식별
예시(데이터 분석): 직접 분석한 데이터셋으로 Claude에 같은 분석을 시켜 결과 비교 → "숫자는 맞는데 전체 패턴을 놓친다" 같은 발견으로 프롬프트 보강.

세 가지 모드 한눈에

데스크톱 앱은 빠른 질문부터 복잡한 리서치, 소프트웨어 제작까지 세 가지 방식으로 Claude와 일하게 해줍니다. Cowork와 Code는 같은 엔진(내부적으로 둘 다 Claude Code) 위에서 돌아갑니다 — 내 컴퓨터에 로컬로 작동하고, 독립적으로 일하며, 서브에이전트를 띄우고, 긴 작업을 지속합니다.

모드한 줄 정의
Chatclaude.ai와 같은 Claude + 컴퓨터에서 네이티브로 실행되는 데서 오는 빠른 진입·스크린샷·받아쓰기·커넥터
Cowork목표를 주고 도구·자료를 연결하면 알아서 일하는 에이전트. 더 넓은 범위로 깊은 리서치·분석과 복잡한 산출물 생산
Code코드 작성·테스트부터 배포까지, 소프트웨어를 만드는 모드

Chat

질문하기, 브레인스토밍, 초안 작성, 문제를 주고받으며 풀기에 강합니다. claude.ai와 동일하되, 컴퓨터에서 네이티브로 실행되어 더해지는 기능이 있습니다.

기능설명

Cowork

여러 출처에서 정보를 끌어와 의미를 만들고 완성품을 내는, 진짜 품이 드는 작업을 위해 설계됐습니다. 멀티태스킹으로 프로젝트의 여러 부분을 동시에 처리해 더 많은 출처를 다루고 끝까지 밀어붙입니다. 시작 전엔 보통 범위·형식·제약을 묻는 짧은 질문으로 계획(plan)을 세워 사이드바에서 검토하게 합니다.

기능설명
폴더 접근컴퓨터의 폴더를 가리키면 내용을 읽고 관련성을 판단해, 완성된 결과를 같은 위치에 저장.
예약 작업반복 업무를 일정에 맞춰 처리(매일 브리핑, 주간 정리, 아침 받은편지함 분류 등). 앱이 열려 있을 때 자동 실행되고, 닫혀 있었으면 복귀 시 따라잡음.
서브에이전트복잡한 작업을 하위 작업으로 쪼개 각자 맥락을 가진 백그라운드 일꾼에게 병렬 배정하고 결과를 모아 하나의 산출물로.
Dispatch폰에서 Cowork 대화를 이어가는 지속 스레드. 모바일 앱에서 내 컴퓨터의 파일·커넥터·플러그인·앱을 쓰는 작업을 맡김(데스크톱+모바일 앱, 컴퓨터 켜짐·앱 열림 필요).
Projects관련 작업을 전용 워크스페이스로 묶음(고유 파일·맥락·지침·메모리). Claude의 프로젝트와 유사하나 데스크톱에 로컬로 존재.
브라우저 사용Chrome에 연결하면 사이트를 탐색·조작해 찾은 내용을 작업에 끌어옴(예: 10개 사이트 경쟁사 가격 확인).
컴퓨터 사용커넥터·플러그인이 없을 때 직접 클릭·입력·앱 실행. 커넥터 → Chrome → 화면 조작 순으로 가장 빠른 경로 선택. 앱 접근 전 권한 확인, 차단 목록 설정 가능. (Pro·Max, macOS 리서치 프리뷰)
플러그인자체로 없는 능력 부여(실시간 금융 데이터, 사내 지식 검색, 특정 컴플라이언스 등). Cowork에서 찾아 추가.
보호된 환경컴퓨터 내 격리 공간에서 실행. 공유한 폴더 안에서만 읽기·생성·수정, 바깥은 접근 불가.
이럴 때: "지난 분기 가격 결정을 회의록·Slack·이메일에서 모아 Q3 덱을 업데이트해줘" / 경쟁사 조사를 탭 하나 열지 않고 출처 포함 브리프로 / 계약·재무·회의록 50개 폴더를 전부 읽어 요약 메모로("다섯 개 보듯 쉰 개를 검토") / 매일 아침 상태 업데이트를 예약 작업으로.
Cowork는 Pro·Max·Team·Enterprise에서 사용 가능하며 기능이 계속 추가됩니다.

프로젝트란?

프로젝트는 자체 메모리·대화 기록·지식 베이스·맞춤 지침을 갖춘 독립 워크스페이스입니다. 특정 업무 흐름을 위한 전용 환경이라고 생각하면 됩니다. 한 번 올린 자료는 그 프로젝트의 모든 대화가 참조하므로 같은 파일을 매번 다시 올릴 필요가 없습니다.

핵심 요소역할
프로젝트 지식 (Knowledge)올린 문서를 Claude가 모든 대화에서 참조. 반복 업로드 제거.
프로젝트 지침 (Instructions)톤·전문성 수준·응답 형식 등 Claude의 행동을 모든 대화에 일괄 적용.
자동 확장 (RAG)지식이 컨텍스트 한계에 가까워지면 자동으로 RAG 모드 전환 → 용량 최대 10배, 품질 유지.
협업 (Team·Enterprise)팀원과 공유해 같은 맥락·지침·축적된 지식을 함께 사용.
일회성 질문이 아니라 반복적으로 쓰는 자료, 일관된 응답 규칙, 팀 협업이 필요한 지속 업무일 때 프로젝트가 빛납니다.

첫 프로젝트 만들기

1단계 · 프로젝트 설정

왼쪽 사이드바 → "Projects"(또는 claude.ai/projects) → 우측 상단 + New Project. 설명적인 이름(예: "Q4 Marketing Campaign")과 간단한 설명을 적습니다. 설명은 Claude가 직접 보지는 않지만 나와 팀원이 목적을 이해하는 데 도움이 됩니다. 공개 범위(비공개 / 조직 공유)도 선택합니다.

2단계 · 프로젝트 지침

모든 대화에 적용될 행동 규칙을 적습니다. "Instructions" 패널을 열고 작성 후 Save instructions.

좋은 지침 요소예시
작업 맥락"이 프로젝트는 B2B 소프트웨어 마케팅 콘텐츠 제작용이다."
프로세스"먼저 독자를 끌 블로그 구조를 짠 뒤 초안을 써라."
톤·스타일"전문적이되 대화체로. 가능하면 전문용어를 피하라."
요구사항"마케팅 카피 끝엔 항상 CTA를 넣어라."
지침으로 워크플로우를 자동화할 수도 있습니다 — "회의록을 올리면 이 템플릿으로 구조화된 요약을 만들어라". 지침은 이 프로젝트용 Claude 동작을 '프로그래밍'하는 것과 같습니다.

3단계 · 지식 베이스 구축

프로젝트 메인 오른쪽 파일 메뉴의 + 버튼으로 PDF·DOCX·CSV·TXT·HTML 등을 올리거나 Google Drive를 연결합니다. 올리면 좋은 것: 참조 문서(브랜드 가이드·스타일 가이드·템플릿), 배경 자료(리서치·회의록·요구사항), 모방하길 원하는 작업 예시, 기술 문서.

파일명 팁 · Claude는 파일명으로 내용을 파악하고 검색합니다. "document1.pdf"보다 "Q4-2024-Brand-Guidelines.pdf"가 훨씬 유용합니다.

대용량 지식 처리 — RAG

지식이 컨텍스트 한계에 가까워지면 Claude는 RAG(Retrieval Augmented Generation) 모드를 자동으로 켭니다. 모든 내용을 한꺼번에 메모리에 올리는 대신, 질문에 필요한 가장 관련 있는 부분만 검색해 가져옵니다. 용량이 최대 10배로 늘어나지만 사용 경험은 동일하고, RAG가 켜지면 시각적 표시가 나타납니다.

협업 (Claude for Work)

프로젝트 공유 시 세 가지 권한 수준을 고를 수 있습니다.

권한할 수 있는 것

Can edit지침 수정·지식 갱신·멤버 관리 등 전면 협업.

공유하려면 프로젝트 이름 우측의 Share project → 이름·이메일로 멤버 추가(또는 이메일 목록 일괄 붙여넣기), 혹은 "Everyone at [조직]"으로 조직 내 공개. 공유 시 팀원에게 이메일 알림이 가고, 그들은 "Shared with me" 탭에서 찾습니다.

아티팩트란?

아티팩트는 Claude가 대화 옆 전용 창에 만들어 주는 독립적이고 상호작용 가능한 산출물입니다. 긴 코드·텍스트가 채팅에 파묻히는 대신, 작동하는 웹사이트·차트·바로 내려받을 수 있는 문서로 렌더링되어 보입니다. Claude는 다음 조건에 맞으면 자동으로 아티팩트를 만듭니다.

  • 의미 있고 자기완결적인 내용 — 보통 15줄 이상
  • 수정·반복·재사용할 가능성이 높은 것
  • 주변 대화 없이도 독립적으로 성립하는 복잡한 내용
  • 나중에 참조하거나 다시 쓸 내용

첫 아티팩트 만들기

그냥 원하는 것을 말하면 됩니다 — Claude가 아티팩트로 보여줄지 판단합니다. 예: "고객 온보딩 프로세스 플로차트를 만들어줘", "월별 지출을 입력하면 분석해 주는 대시보드를 만들어줘", "생산성 앱 랜딩 페이지를 히어로+기능 목록으로 디자인해줘". 자동으로 안 만들면 "이걸 아티팩트로 만들어줘"라고 명시하면 됩니다. 생성되면 대화 오른쪽 전용 창에 뜨고, 거기서 미리보기↔코드 전환·복사·다운로드가 가능합니다.

공유 & 게시

방법설명
복사·다운로드개인용이나 다른 채널 공유. 아티팩트 창 우측 하단 버튼.
조직 내 공유 (Work)Team·Enterprise는 동료와 내부 공유. 조직 안에 머물며 팀 인증 필요.
공개 게시 (Free·Pro·Max)링크 가진 누구나 접근. 선택한 버전만 공개(대화는 비공개), 계정 없이도 보고 조작 가능, 타인이 "remix"로 자기 대화에서 변형 가능.
게시한 아티팩트는 링크가 있으면 계정 없이 누구나 볼 수 있습니다. 단, 검색엔진에는 색인되지 않아 구글 결과엔 안 뜹니다. 언제든 공개를 해제할 수 있습니다.

잘 쓰는 팁

  • 원하는 바를 구체적으로 — "예산 추적기"보다 "카테고리별 지출 입력 + 파이차트 + 초과 시 경고가 있는 월별 예산 추적기".
  • 최종 사용자를 알려주기 — "신입사원용 플로차트"는 "엔지니어링팀용"과 다른 결과를 낳음.
  • 점진적으로 반복 — 한 번에 기능 하나씩 추가·변경하면 문제를 일찍 잡음.
  • 필요하면 명시적으로 요청 — 채팅으로 답하면 "그걸 아티팩트로 만들어줘".

Skills란?

Skills는 Claude가 특정 작업을 잘하기 위해 동적으로 불러오는 지침·스크립트·자료의 폴더입니다. '전문성 패키지'라고 생각하면 됩니다 — 특정 작업을 반복 가능한 방식으로 수행하도록 가르칩니다. Excel·PPT·Word·PDF를 만들어 본 적 있다면 이미 Skills를 쓴 것입니다(뒤에서 동작). 분기별 변동 분석 방법론, 브랜드 보이스 리뷰 절차, 컴플라이언스 체크리스트 같은 반복 워크플로우 전체를 코드화해 매번 같은 단계를 따르게 할 수 있습니다.

종류설명
Anthropic SkillsAnthropic이 만들고 유지. Excel·Word·PPT·PDF 문서 생성 등. 모든 유료 사용자에게 제공되며 관련 상황에서 자동 호출 — 따로 할 일 없음.
Custom Skills나·조직이 특정 워크플로우용으로 만든 것. 예: 회사 브랜드 가이드를 발표에 적용, 회의록을 특정 형식으로 구조화, 데이터 분석 절차 실행.

Skills 켜기

Skills는 Claude의 보안 샌드박스 환경이 필요하므로 코드 실행·파일 생성이 켜져 있어야 합니다.

  • Settings → Capabilities 이동
  • Code execution and file creation 켜기
  • Skills 섹션으로 스크롤 → 개별 스킬 on/off

Enterprise는 Owner가 Admin 설정에서 코드 실행·Skills를 먼저 켜야 하고, Team은 기본적으로 켜져 있습니다.

실제 사용 & 파일 작업

대개 Skills를 신경 쓸 필요가 없습니다 — Claude가 요청에 맞춰 자동 선택합니다. 예: "월별 지출과 합계 수식이 있는 Excel을 만들어줘", "이 회의록을 PPT로 바꿔줘", "이 데이터로 PDF 리포트를 만들어줘". 스킬을 쓰면 Claude의 사고 과정에 표시되고, 결과는 내려받거나 Google Drive에 바로 저장할 수 있는 파일입니다. 또한 슬라이드·스프레드시트·계약서(.xlsx·.pptx·.docx·.pdf)를 올리면 격리 환경에서 분석·수정본을 만들어 줍니다(Chat에서는 원본 대신 새 버전 생성).

보안 · Skills는 실행 코드를 포함할 수 있으니 신뢰할 수 있는 출처에서만. 내장 Skills는 Anthropic이 검증·유지하고, 내가 올린 커스텀 스킬은 내 계정에만 비공개. 외부 스킬은 쓰기 전에 내용을 검토하세요.

커스텀 스킬 만들기

가장 쉬운 방법은 Claude와 대화하는 것입니다 — 코드를 쓰거나 파일을 직접 만들 필요 없이 Claude가 구조를 처리합니다.

  • 새 채팅에서 만들고 싶은 것을 말하기 — "분기 사업 리뷰 작성 스킬을 만들고 싶어"
  • Claude의 질문에 답하기 — 무엇을 하는지, 좋은 결과란 무엇인지, 언제 쓰는지 인터뷰
  • 참고 자료(템플릿·스타일 가이드·예시) 올리기
  • 저장하기 — Claude가 구조화된 스킬 파일을 생성, 저장하면 바로 사용 가능

왼쪽 사이드바 Customize 탭에서 사용 가능한 모든 스킬을 보고, 수동 또는 대화로 편집할 수 있습니다. 이후 관련 작업마다 자동 호출됩니다.

둘 다 맥락을 주지만 역할이 다릅니다 — 프로젝트는 지식을 저장하고, 스킬은 작업을 수행합니다.

커넥터란?

Research란?

Research는 Claude를 대화형 어시스턴트에서 체계적 조사자로 바꾸는 고급 기능입니다. 한 번의 검색이 아니라 에이전트처럼 작동해, 찾은 내용을 바탕으로 다음에 무엇을 조사할지 스스로 정하며 서로 이어지는 여러 검색을 수행합니다. 웹과 연결된 통합에서 정보를 종합해, 보통 몇 시간 걸릴 일을 5~15분(복잡하면 최대 45분)에 끝냅니다. 모든 주장에 검증 가능한 인용이 붙고, 확장 사고가 자동으로 켜집니다.

언제 쓰나 — 다른 기능과 비교

기능이럴 때
Research여러 출처를 종합한 포괄 리포트, 경쟁·벤더 비교 분석, 수 시간짜리 조사, 인용이 필요한 심층 조사. (시장·경쟁 분석, 복잡한 기획, 이메일·캘린더·문서 종합 등)
웹 검색빠르고 구체적인 사실 하나(주가·주소), 출처 한두 개로 충분, 포괄성보다 속도가 중요할 때.
확장 사고외부 정보 없이 복잡한 문제를 깊이 추론(수학·코드 디버깅·논리 분석). 정보 수집이 아닌 추론으로 답이 나올 때.
Enterprise Search조직 내부 지식(문서·Slack·이메일·회의록)에서 답을 찾을 때, 공개 웹이 아닌 사내 특화 질문.

작동 방식 (4단계)

단계설명
1. 계획확장 사고가 자동 활성화 → 요청을 분해하고 필요한 정보와 조사할 각도를 설계.
2. 다중 검색한 번이 아니라 서로 이어지는 여러 검색 수행. 찾은 것에 따라 다음을 정하고 빈틈을 메움.
3. 종합웹과 연결된 통합(Gmail·Calendar·Drive 등)에서 모은 정보를 잘 구조화된 리포트로 정리.
4. 인용모든 주장이 출처로 연결되어 검증·심화가 쉬움.
켜는 법 · 채팅 좌측 하단 + → Research 선택(활성 시 강조) → 프롬프트 입력. 진행 표시가 뜨고 백그라운드로 작동. 웹 검색이 켜져 있어야 작동합니다.

효과적인 프롬프트 팁

  • 목표를 구체적으로 — "EV 시장 알려줘"보다 "전기차 배터리 시장 분석 — 주요 기업, 기술 트렌드, 투자 결정에 영향 줄 공급망 과제".
  • 원하는 구조·섹션 명시 — "팀 오프사이트 장소 비교: 위치·접근성, 회의 공간, 케이터링, 가격".
  • 제약 포함 — 예산·일정·지역 등으로 초점을 좁힘.
  • 프롬프트를 다듬어 달라고 요청 — 기능 켜기 전 Claude에게 더 나은 Research 프롬프트 작성을 부탁할 수도.
통합과 함께 쓰면 더 강력 — "Project X에 대해 이메일·Slack에서 논의된 내용을 요약하고, 유사 이니셔티브의 업계 베스트 프랙티스를 조사해줘". 웹 검색을 꺼서 사내 도구만 대상으로 한 내부 전용 리서치도 가능합니다.
