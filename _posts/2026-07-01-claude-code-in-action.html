Setup · 레슨 04

Claude Code 설치

🎬 영상 + 아티클 ▶ 영상 보기

Claude Code를 로컬에 설치하는 방법을 다룹니다. 전체 설치 가이드는 공식 quickstart 문서를 참고하세요.

설치 명령

  • macOS · Linux · WSL — curl -fsSL https://claude.ai/install.sh | bash
  • Windows PowerShell — irm https://claude.ai/install.ps1 | iex
  • Windows CMD — curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
  • macOS (Homebrew) — brew install --cask claude-code

설치 후 터미널에서 claude를 실행합니다. 처음 실행하면 컬러 테마 선택과 claude.ai 계정 인증을 거칩니다.

문제 해결 · claude가 인식되지 않거나 네트워크·권한 오류가 나면 문서의 "Troubleshoot installation issues"를 확인하세요. Amazon Bedrock·Google Cloud Vertex AI·Microsoft Foundry를 통해 쓰는 경우 third-party provider setup 안내를 따르세요.

Setup · 레슨 05

프로젝트 세팅

🎬 영상 + 아티클 ▶ 영상 보기

Claude Code를 체험하기 좋은 예제 프로젝트를 준비합니다. 이전 영상에 등장한 UI 생성 앱(uigen)과 동일한 프로젝트로, 강의를 따라가는 데 사용합니다. 꼭 이 프로젝트를 쓰지 않아도 되며, 자신의 코드베이스로 진행해도 됩니다.

세팅 절차

  • 로컬에 Node.js가 설치되어 있는지 확인
  • 강의에 첨부된 uigen.zip을 내려받아 압축 해제
  • 프로젝트 디렉터리에서 npm run setup — 의존성 설치 + 로컬 SQLite DB 생성
  • npm run dev로 프로젝트 시작
선택 · 이 앱은 Anthropic API로 UI 컴포넌트를 생성합니다. 전체 기능을 테스트하려면 Anthropic 콘솔에서 API 키를 받아 .env 파일의 your-api-key-here를 교체하세요. 생략해도 앱은 정적 예시 코드를 생성합니다.

Hooks 관련 주의점

🎬 영상 + 아티클

npm run setup 후 .claude 디렉터리에 settings.json 파일이 두 개 생기는 이유와, hook 설정을 팀과 공유할 때의 함정을 다룹니다.

  • 절대경로 권장 — Claude Code 문서는 보안상 스크립트를 상대경로 대신 절대경로로 지정하길 권장합니다(경로 가로채기·바이너리 심기 공격 완화).
  • 공유의 어려움 — 하지만 절대경로는 사람마다 프로젝트 위치가 달라 settings.json을 그대로 공유하기 어렵게 만듭니다.
  • 해결책 — $PWD 플레이스홀더 — 프로젝트에는 settings.example.json이 있고, 스크립트 참조에 $PWD 플레이스홀더를 씁니다.
  • init-claude.js — npm run setup이 실행하는 이 스크립트가 $PWD를 내 머신의 절대경로로 치환하고, settings.example.json을 복사해 settings.local.json으로 만듭니다.
덕분에 권장 방식(절대경로)을 지키면서도 설정 파일을 팀과 공유할 수 있습니다.

Hooks · 레슨 17

또 하나의 유용한 Hook

🎬 영상 + 아티클

이 코스에서 다룬 PreToolUse·PostToolUse 외에도 다양한 hook 이벤트가 있으며, 각 이벤트마다 명령에 전달되는 stdin 입력 구조가 다르다는 점을 다룹니다.

추가 hook 이벤트

  • Notification — Claude가 권한을 요청하거나 60초간 유휴 상태일 때
  • Stop — Claude가 응답을 마쳤을 때 / SubagentStop — 서브에이전트(Task) 완료 시
  • PreCompact — 수동·자동 compact 직전 / UserPromptSubmit — 프롬프트 제출 시
  • SessionStart · SessionEnd — 세션 시작·재개 / 종료 시

헷갈리는 부분은 hook 종류에 따라 stdin 입력 구조가 바뀌고, PreToolUse·PostToolUse에서는 호출된 도구에 따라 tool_input도 달라진다는 점입니다.

디버깅 팁 · 어떤 데이터가 들어오는지 모를 때, matcher *에 jq . > post-log.json 명령을 거는 헬퍼 hook을 만들면 실제 입력 전체를 파일로 확인할 수 있어, 내 명령이 무엇을 검사해야 할지 파악하기 쉬워집니다.
