코스 개요 & Claude 모델

🎬 영상 강의
이 강의는 76개 레슨이 대부분 영상으로 진행되는 영상 중심 강의입니다. 그래서 여기서는 레슨을 하나씩 옮기는 대신 모듈별 핵심 개요를 한국어로 정리하고, 각 레슨에는 원문 영상 링크를 달아 두는 방식으로 구성했습니다.

강의의 시작 모듈로, 코스가 무엇을 다루는지 소개하고 Anthropic이 제공하는 Claude 모델 라인업을 개괄합니다. 각 모델의 성격과 용도를 훑어 이후 실습에서 어떤 모델을 고를지 감을 잡게 해 줍니다.

레슨

  • 코스에 오신 것을 환영합니다 ▶ 영상 — 강의 목표와 전체 흐름 소개.
  • Claude 모델 개요 ▶ 영상 — Claude 모델 종류와 각 모델의 특성.
