코스 소개

🎬 영상 ▶ 영상 보기
이 강의는 영상 중심 강의입니다. 레슨 대부분이 별도 아티클 본문 없이 영상으로 진행되므로, 이 페이지는 각 레슨의 핵심 주제 개요 + 원문 영상 링크로 정리했습니다. 자세한 실습·화면 시연은 원문 영상을 직접 참고하세요.

이 코스가 무엇을 다루는지, 어떻게 진행되는지 소개하는 오리엔테이션 레슨입니다. MCP(Model Context Protocol)의 개념부터 서버·클라이언트를 직접 구축하고 도구·리소스·프롬프트를 다루는 전체 여정을 개관합니다.

소개 · 레슨 02

MCP 소개

🎬 영상 ▶ 영상 보기

MCP(Model Context Protocol)가 무엇이고 왜 필요한지 개념을 잡는 레슨입니다. Claude 같은 AI 모델을 외부 도구·데이터 소스에 표준화된 방식으로 연결해 주는 개방형 프로토콜로서, 통합을 매번 새로 만들 필요 없이 재사용 가능한 인터페이스를 제공한다는 점을 살펴봅니다.

소개 · 레슨 03

MCP 클라이언트

🎬 영상 ▶ 영상 보기

MCP 아키텍처에서 클라이언트가 어떤 역할을 하는지 다룹니다. 클라이언트는 AI 애플리케이션 쪽에서 MCP 서버와 연결을 맺고, 서버가 노출하는 도구·리소스·프롬프트를 발견해 모델이 활용할 수 있게 중개합니다. 서버와 클라이언트가 어떻게 짝을 이루는지 큰 그림을 잡습니다.

04
서버 구축 · 레슨 04

프로젝트 세팅

🎬 영상 ▶ 영상 보기

MCP 서버를 직접 만들어 보기 위한 실습 프로젝트를 준비하는 레슨입니다. 개발 환경과 기본 프로젝트 구조를 세팅하고, 이후 레슨에서 도구·리소스·프롬프트를 붙여 나갈 뼈대를 마련합니다.

MCP로 도구 정의하기

🎬 영상 ▶ 영상 보기

MCP 서버에서 도구(tool)를 정의하는 방법을 다룹니다. 도구는 모델이 호출해 실제 동작을 수행하는 함수로, 이름·설명·입력 스키마를 지정해 노출합니다. Claude가 언제 어떤 도구를 쓸지 판단할 수 있도록 설계하는 방법을 살펴봅니다.

서버 구축 · 레슨 06

서버 인스펙터

🎬 영상

MCP 서버를 개발하며 동작을 확인할 수 있는 인스펙터(inspector) 도구를 다룹니다. 서버가 노출한 도구·리소스·프롬프트를 시각적으로 살펴보고, 실제 클라이언트 없이도 요청을 보내 응답을 검증하며 디버깅할 수 있습니다.

클라이언트 구현하기

🎬 영상 ▶ 영상 보기

MCP 클라이언트를 직접 구현하는 실습 레슨입니다. 서버에 연결을 맺고, 노출된 도구 목록을 받아와 호출하는 흐름을 코드로 작성해 봅니다. 서버와 클라이언트가 프로토콜을 통해 어떻게 주고받는지 실제로 확인합니다.

리소스 정의하기

🎬 영상 ▶ 영상 보기

MCP 서버에서 리소스(resource)를 정의하는 방법을 다룹니다. 리소스는 모델에 읽기 전용 컨텍스트를 제공하는 데이터로, 파일·문서·DB 레코드 등을 URI로 노출합니다. 도구가 "행동"이라면 리소스는 "참조 데이터"라는 구분을 이해하는 레슨입니다.

리소스에 접근하기

🎬 영상 ▶ 영상 보기

클라이언트 쪽에서 서버가 노출한 리소스를 조회·접근하는 방법을 다룹니다. 사용 가능한 리소스 목록을 받아오고, 특정 리소스를 읽어 그 내용을 모델의 컨텍스트로 넘기는 실전 흐름을 살펴봅니다.

프롬프트 정의하기

🎬 영상 ▶ 영상 보기

MCP 서버에서 프롬프트(prompt)를 정의하는 방법을 다룹니다. 프롬프트는 서버가 미리 제공하는 재사용 가능한 프롬프트 템플릿으로, 사용자가 선택하면 정해진 형식의 요청을 손쉽게 구성할 수 있습니다. 도구·리소스와 함께 MCP의 세 번째 핵심 기본 요소입니다.
