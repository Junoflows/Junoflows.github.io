코스 시작하기

🎬 영상 ▶ 영상 보기
이 강의는 영상 중심 강의입니다. 레슨 대부분이 별도 아티클 본문 없이 영상으로 진행되므로, 이 페이지는 각 레슨의 핵심 주제 개요 + 원문 영상 링크로 정리했습니다. 자세한 실습·화면 시연은 원문 영상을 직접 참고하세요.

MCP의 심화 주제를 다루는 이 코스가 무엇을 담고 있는지 소개하는 오리엔테이션 레슨입니다. 기본 서버·클라이언트를 넘어 샘플링, 로그·진행 알림, 루트(roots), 그리고 다양한 전송(transport) 방식까지 어떤 고급 기능을 배우게 될지 전체 여정을 개관합니다.

핵심 고급 기능 · 레슨 02

샘플링(Sampling)

🎬 영상 ▶ 영상 보기

MCP의 샘플링(sampling) 기능을 개념적으로 소개하는 레슨입니다. 샘플링은 서버가 도구 실행 도중 필요할 때 클라이언트를 거쳐 언어 모델에 추론을 요청할 수 있게 해 주는 메커니즘으로, 서버 자신이 직접 API 키나 모델을 갖지 않고도 모델의 생성 능력을 활용할 수 있습니다.

샘플링 워크스루

🎬 영상 ▶ 영상 보기

샘플링을 실제 코드로 구현하는 과정을 단계별로 따라가는 실습 레슨입니다. 서버에서 create_message()로 모델에 보낼 메시지를 구성해 샘플링을 시작하고, 클라이언트 쪽에 샘플링 콜백을 정의해 연결한 뒤, 생성된 텍스트를 반환받아 결과로 사용하는 흐름을 살펴봅니다.

로그·진행 알림

🎬 영상 ▶ 영상 보기

서버가 클라이언트에 로그 메시지와 진행 상황(progress) 알림을 보내는 기능을 소개하는 레슨입니다. 오래 걸리는 도구 작업을 수행할 때 중간 상태를 사용자에게 전달해, 무엇이 진행되고 있는지 실시간으로 알려 줄 수 있습니다.

알림 워크스루

🎬 영상 ▶ 영상 보기

로그·진행 알림을 코드로 구현하는 실습 레슨입니다. 도구 함수가 마지막 인자로 자동으로 받는 Context 객체를 활용해 로그와 진행 상황을 보고하고, 클라이언트 쪽에서 이를 받아 처리할 콜백을 정의해 연결하는 방법을 따라갑니다.

루트(Roots)

🎬 영상

MCP의 루트(roots) 개념을 소개하는 레슨입니다. 루트는 서버가 접근할 수 있는 파일·폴더의 경계를 사용자가 지정하는 방식으로, 어떤 파일시스템 위치에 접근을 허용할지 클라이언트가 서버에 알려 주어 안전한 파일 접근 범위를 설정합니다.

핵심 고급 기능 · 레슨 07

루트 워크스루

🎬 영상 ▶ 영상 보기

루트를 실제로 구현하는 과정을 단계별로 살펴보는 실습 레슨입니다. 사용자가 CLI 인자로 허용할 경로 목록을 전달하면, 클라이언트가 이를 루트 객체로 만들어 서버에 노출하고, 서버는 루트 콜백을 통해 허용된 경로를 확인해 접근 권한을 검증하는 흐름을 다룹니다.

전송과 통신 · 레슨 08

JSON 메시지 타입

🎬 영상

MCP가 통신에 사용하는 JSON 메시지 타입을 다루는 레슨입니다. MCP는 JSON-RPC 기반으로 요청·응답·알림 등 여러 형식의 메시지를 주고받는데, 이러한 메시지 구조를 이해하면 전송 계층에서 실제로 어떤 데이터가 오가는지 파악할 수 있습니다.

STDIO 전송

🎬 영상

STDIO 전송(transport) 방식을 다루는 레슨입니다. STDIO는 표준 입출력 스트림을 통해 클라이언트와 서버가 통신하는 방식으로, 주로 같은 머신에서 로컬 프로세스로 실행되는 MCP 서버에 적합합니다. 언제 이 전송 방식을 선택하는지 살펴봅니다.

전송과 통신 · 레슨 10

StreamableHTTP 전송

🎬 영상 ▶ 영상 보기

StreamableHTTP 전송 방식을 소개하는 레슨입니다. HTTP를 기반으로 하여 원격에서 MCP 서버와 통신할 수 있게 해 주는 전송으로, 네트워크 너머의 서버에 연결하거나 스트리밍 응답을 다루어야 하는 상황에서 사용됩니다. STDIO와의 차이를 이해하는 데 초점을 둡니다.

StreamableHTTP 심화

🎬 영상 ▶ 영상 보기

StreamableHTTP 전송을 더 깊이 파고드는 레슨입니다. 이 전송이 내부적으로 어떻게 동작하는지, 요청과 스트리밍 응답이 어떤 방식으로 처리되는지 자세히 살펴보며, 원격 MCP 서버를 구성할 때 알아 두어야 할 세부 사항을 다룹니다.

StreamableHTTP와 상태

🎬 영상 ▶ 영상 보기

StreamableHTTP 전송에서 상태(state)를 어떻게 다루는지 살펴보는 레슨입니다. HTTP 기반 연결에서 세션 상태를 유지할지 상태 없이(stateless) 운영할지에 따라 서버 설계가 달라지며, 각 방식의 특징과 고려 사항을 이해합니다.
